# cosc-650-applied-llm-systems

This Repository is for Applied LLM Systems (COSC 650). It contains weekly assignments, research, experiments, and more.
# Course Context

An Applied LLM Systems course is an eight-week course given for graduate students at Maryville University, focusing on the design and implementation of Large Language model systems. The coursework covers tokenization, transformer architecture, prompt Engineering, functional calling, retrieval-augmented generation, fine-tuning, and evaluation.
