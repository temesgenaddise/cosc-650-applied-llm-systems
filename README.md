# cosc-650-applied-llm-systems

This Repository is for Applied LLM Systems (COSC 650). It contains weekly assignments, research, experiments, and more.
# Course Context

Applied LLM Systems is an eight-week course for graduate students at Maryville University, focusing on the design and implementation of large language model systems. The coursework covers tokenization, transformer architecture, prompt Engineering, function calling, retrieval-augmented generation, fine-tuning, and evaluation.
