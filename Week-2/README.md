# Week-2 Inference and Sampling Assignment

Week-2 assignment traced a given short prompt, “Artificial Intelligence can help people,” using DistilGPT2 tensors, from token IDs to embeddings, attention, and logits. It then applied temperature, top-k, and top-p to the model's next-token distribution, visualized the individual methods and their combinations, evaluated three settings using quantitative metrics, and demonstrated why top-p equal to 1.0 does not filter the vocabulary.
